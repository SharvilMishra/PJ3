RULE 01 · COST AWARENESS SAMPLE RULE · —

Peak appliance shift

Suggest a lower-cost window when a flexible appliance runs during peak pricing.

How this rule works

Example condition: dishwasher load is above zero during a peak tariff. Multiple matching rules use the documented priority order.

☾
RULE 02 · COMFORT FIRST SAMPLE RULE · —

Night heating reduction

Offer a gentler heating suggestion on mild nights, with comfort kept in mind.

How this rule works

Example condition: before 5 AM, HVAC is heating, and outdoor temperature is above 10°C. No equipment is adjusted automatically.

⌁
RULE 03 · NATURAL COOLING SAMPLE RULE · —

Mild-weather cooling

Point out a cooler outdoor window when it may be comfortable to reduce cooling.

How this rule works

Example condition: HVAC is cooling and outdoor temperature is no higher than indoor temperature. Priority resolves conflicts with other example rules.

i

Reference rules, not optimized rules. The backend reports raw rule matches, test counts, and overlaps. Sparse test rows share timestamps with training, so these counts are an audit rather than a holdout score. Rule switches are a frontend preview and are not saved.
