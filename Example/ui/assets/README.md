# UI design assets

Place Canva exports and supporting UI/UX assets in this folder. The editable Canva design and view links are recorded in [CANVA_DESIGN.md](CANVA_DESIGN.md). Keep screen exports and related design files together, and preserve a short source note if an asset needs context. The original `Energy Saving_Example.html` remains in `Datasets/` as the reference.

The custom vector brand assets are [energy-advisor-logo.svg](energy-advisor-logo.svg) (wordmark) and [energy-advisor-mark.svg](energy-advisor-mark.svg) (icon only). They are authored from SVG paths and shapes, so they remain scalable and editable rather than being raster images.
