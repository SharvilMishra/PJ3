# Canva UI design handoff

**Design:** Energy Advisor dashboard website  
**Format:** Editable, one-page Canva website design  
**Canva design ID:** `DAHYYL4k54g`

- [Open and edit in Canva](https://www.canva.com/d/gMEG4NUp4H_SsMN)
- [View the Canva design](https://www.canva.com/d/vBuA2WHjs7204RA)

The saved Canva reference follows a charcoal/near-black base with neon blue and neon purple accents. The local Energy Advisor frontend now uses the project-matched Crimson Pulse palette: charcoal surfaces, crimson red (#FF365D), neon purple (#D65DFF), and a supporting violet (#B64DFF). The online Canva reference has not been changed. The generated Canva design is online and editable. This folder currently stores its handoff links; the Canva connector did not provide a direct export-to-folder operation, so local PNG/SVG exports are not included yet.

The custom vector logo source is available locally as [energy-advisor-logo.svg](energy-advisor-logo.svg) and [energy-advisor-mark.svg](energy-advisor-mark.svg). The connector rejected uploading the local SVG to Canva, so these vector files have not been inserted into the online design.
